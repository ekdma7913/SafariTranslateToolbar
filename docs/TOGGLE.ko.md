# 번역 토글 (1.2.0)

[KO](TOGGLE.ko.md) | [EN](TOGGLE.md)

## 동작

- Safari의 ‘원본 보기’ 명령이 활성화돼 있으면 원문으로 복귀하고, 아니면 번역 언어를
  선택합니다. 배지 표시로 실제 동작을 결정하지 않습니다.
- 명령 실행 뒤 내장 메뉴를 잠시 확인합니다. 예상한 상태가 확인돼야 `ON`을 켜거나
  끕니다. 확인 실패·시간 초과는 `?`, 처리 중에는 `…`를 표시합니다. Safari가 툴바 색을
  제어하므로 색상은 최선의 시도이며, 활성 SVG의 모양과 `ON` 배지도 함께 바뀝니다.
- 매 클릭의 무작위 UUID로 응답을 연결합니다. 처리 중 탭 로딩·닫기·전환이 발생하면
  늦은 응답을 무시하며, 연속 클릭을 쌓아 두지 않습니다.
- 표시는 마지막 확인 결과이지 상시 감시 결과는 아닙니다. Safari 메뉴에서 직접 바꾼
  상태는 다음 클릭 때 확인합니다. 브라우저 시작·확장 업데이트·페이지 이동 시 초기화하며,
  백그라운드 일시 중단만으로 초기화하지 않습니다. 느린 번역은 확인 제한 시간 뒤 끝날 수 있습니다.
- 처리가 끝날 때까지 같은 Safari 탭·창을 맨 앞에 유지하세요. 접근성 명령은 Safari의
  포커스 페이지를 대상으로 합니다. 페이지 URL을 읽어 탭을 식별하지 않으므로,
  표시 응답을 무시하더라도 이미 전달된 명령까지 취소할 수는 없습니다.

## 검증

`./scripts/source-audit.sh`, `./scripts/test.sh`(Xcode와 Node.js 18 이상),
서명 없는 universal Xcode 빌드, `git diff --check`를 실행합니다.
Swift 테스트는 원본 명령 매칭·토글 판단·확인 결과·웹 콘텐츠 탐색 차단을 검사합니다.
JavaScript 모의 테스트는 응답 연결, 시간 초과, 전달 실패, 연속 클릭, 페이지 이동,
탭·창 전환, 백그라운드 수명, 배지 색 미지원, URL·제목 미접근을 검사합니다.

2026년 9월 19일 macOS 27.0(26A428), Safari 27, Apple Silicon에서 1.2.0(5)을
서명·공증하고 설치했습니다. 기존 1.1.1 앱을 백업했으며, 손쉬운 사용 신뢰와 확장
활성화 상태는 유지됐습니다. Swift 8개·JavaScript 11개 테스트, 소스 점검,
서명 없는 universal 빌드, 앱·DMG 서명 검사, Gatekeeper 검증을 통과했습니다.

`https://example.com`에서 실제 확장 버튼으로 영어 → 한국어 → 영어 → 한국어 전환을
확인했습니다. 확인된 번역 상태에서 `ON` 배지와 원문 복귀 툴팁이 나타났고, 원문 복귀 시
꺼졌습니다. 새 탭에서는 기본 표시였으며 번역한 탭으로 돌아오면 켜짐 표시가 유지됐습니다.
새로고침 후에는 페이지와 표시가 원문·기본 상태로 돌아갔습니다. 네이티브 포트 전달도
앱 전체 실행 경로에서 검증됐습니다. 배지 색은 요청한 파란색 대신 Safari 자체 색상으로
표시됐습니다.

권한 거부·초기화, 여러 프로필, 영어 시스템 UI, 이전 macOS, Intel 기기,
느리거나 실패하는 네트워크 번역은 추가 수동 검증이 필요합니다.
이 문서는 v1.2.0의 검증 기록이며, 이전 배포 파일은 그대로 유지합니다.
