# Safari 번역 툴바 1.2.1

[KO](RELEASE_NOTES_1.2.1.ko.md) | [EN](RELEASE_NOTES_1.2.1.md)

- 겹쳐서 깨진 글자처럼 보이던 `ON`, `…`, `?` 배지를 제거하며, 1.2.0에서 남은 배지도 지웁니다.
- 확인된 번역은 원형 체크, 처리 중은 모래시계, 원문·미확인 상태는 기본 아이콘으로 표시합니다. 마우스를 올리면 상태 설명이 보이며, 아이콘 색상은 Safari가 결정합니다.
- 한 번 클릭해 번역하고 다시 클릭해 원문으로 돌아가는 동작과 탭별 상태 보호는 유지합니다.
- 권한·페이지 본문 접근·데이터 수집을 추가하지 않았습니다. 소스와 DMG 점검 범위에서 불필요한 개인정보나 인증 정보는 발견되지 않았으며, 공개 Developer ID 서명자 정보는 유지됩니다.
- macOS 13 이상과 Apple Silicon·Intel universal 앱을 지원합니다. 빌드 6은 Developer ID 서명과 Apple 공증을 마쳤습니다.

Swift 8개·JavaScript 11개 테스트, 소스 점검, 앱·DMG 서명 및 Gatekeeper 검증을 통과했습니다. 한국어 macOS 27 / Safari 27의 설치 앱에서 원문 복귀와 재번역, 글자 배지 없는 기본·체크 아이콘을 확인했습니다. 짧게 표시되는 처리 중 모래시계는 자동 모의 테스트로 검증했으나 화면 캡처로 확인하지 못했습니다.

이 릴리스의 DMG를 다운로드해 Applications의 앱을 교체하세요. 기존 설치 앱은 자동 업데이트되지 않습니다.

아이콘은 마지막 확인 결과이며 상시 감시 결과가 아닙니다. 완료될 때까지 같은 탭·창을 맨 앞에 유지하세요. 권한 거부·초기화, 여러 프로필, 영어 시스템 UI, 이전 macOS, Intel 기기, 느리거나 실패하는 번역은 추가 수동 확인이 필요합니다. [검증 기록](TOGGLE.ko.md)을 참고하세요.
