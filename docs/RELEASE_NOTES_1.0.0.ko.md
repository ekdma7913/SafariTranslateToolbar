# Safari 번역 툴바 1.0.0

[English](RELEASE_NOTES_1.0.0.md) | 한국어

첫 공개 버전입니다.

- Safari 도구 막대 버튼으로 Safari의 기존 Apple 번역 기능 실행
- 별도 번역 서비스, 페이지 content script, 계정 및 네트워크 통신 없음
- Apple Silicon 및 Intel Mac 지원
- Developer ID 서명, Apple 공증 및 Gatekeeper 검증
- 손쉬운 사용 권한 요청은 최초 한 번만 표시

설치 방법은 DMG 안의 설치 안내 또는 README를 확인해 주세요.
