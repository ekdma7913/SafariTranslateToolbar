# Safari Translate Toolbar 1.1.1

[KO](RELEASE_NOTES_1.1.1.ko.md) | [EN](RELEASE_NOTES_1.1.1.md)

- 실제 컨트롤 식별자를 이용해 Safari 27 번역 메뉴 탐색을 개선하고 기존 언어별 문구 탐색도 유지했습니다.
- 번역 하위 메뉴를 연 뒤 언어를 선택하며, ‘원본 보기’ 상태로 이미 번역된 페이지를 판별합니다.
- Safari 활성화를 기다리고 Safari가 맨 앞에 있을 때만 메뉴 조작을 수행합니다.
- 손쉬운 사용 탐색에서 웹 콘텐츠 하위 트리를 제외하고 탐색량을 제한했습니다.
- 영어·한국어 오류 안내를 개선하고 릴리스 패키징에 회귀 테스트 6개를 추가했습니다.
- 시스템 권한 창을 반복 요청하지 않는 macOS 27 권한 복구 안내와, 개인정보 없이 상태를 출력하는 `--diagnose`를 추가했습니다.
- macOS 13 최소 지원, Apple Silicon·Intel 바이너리, 기존 앱 식별자와 최초 1회 권한 요청을 유지했습니다.

검증 범위와 남은 확인 사항은 [macOS 27 점검 문서](MACOS27.ko.md)를 참고하세요.
