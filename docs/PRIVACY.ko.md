# 개인정보 및 권한 점검

[English](PRIVACY.md) | 한국어

## 수집하는 데이터

없습니다.

이 앱은 계정, 서버, 네트워크 요청, 분석 SDK, 광고 SDK, 충돌 수집기, 업데이트 추적기, 원격 로그를 사용하지 않습니다. 소스에도 개발자 개인 이름, 이메일, 사용자 홈 경로, Apple ID, 공증 암호를 저장하지 않습니다.

서명된 앱 파일에는 Apple이 발급한 Developer ID 인증서의 법적 서명자 이름과 Team ID가 표시됩니다. 이는 Gatekeeper가 배포자를 검증하는 공개 서명 정보입니다. 소스 설정에는 공개 식별에 필요한 Team ID만 들어 있습니다.

## Safari 확장 권한

manifest가 선언하는 권한은 `nativeMessaging` 하나입니다.

- 웹페이지 내용 읽기 권한 없음
- 모든 웹사이트 접근 권한 없음
- content script 없음
- 탭의 URL·제목 수집 없음
- 클립보드 권한 없음
- 네트워크 권한 없음

버튼 클릭 시 `nativeMessaging`은 고정된 로컬 `translate` 명령과 매번 무작위로 생성한
UUID를 전달합니다. 앱은 네이티브 포트로 같은 UUID와 상태(`translated`, `original`,
`unknown`)를 응답합니다. 페이지 본문, URL, 쿠키, 입력 내용은 전달하지 않습니다.
확장은 탭·창의 숫자 ID와 로딩 이벤트만 메모리에서 이용해 표시를 연결하고 오래된 응답을
무시합니다. `tabs`·웹사이트·저장소·App Group 권한은 추가하지 않으며 상태도 저장하지 않습니다.

## macOS 손쉬운 사용 권한

Safari는 내장 Apple 번역을 확장에서 직접 실행하는 공개 API를 제공하지 않습니다. 따라서 컨테이너 앱이 손쉬운 사용 API로 현재 Safari 창의 번역 메뉴를 찾아 누릅니다.

- 대상 프로세스를 Bundle ID `com.apple.Safari`로 고정
- 역할 정보로 Safari 도구 막대·메뉴·팝오버 범위를 탐색
- `AXWebArea`의 자식 요소를 요청하기 전에 탐색을 중단하여 웹페이지 내부의 도구 막대·메뉴가 번역 후보에 포함되지 않도록 처리. 역할을 읽을 수 없는 요소도 제외
- 번역 관련 컨트롤의 제목·설명·도움말·식별자만 검색
- 페이지 입력값이 노출될 수 있는 `AXValue`는 읽지 않음
- 검색 결과를 파일이나 네트워크에 기록하지 않음
- 페이지 본문을 읽거나 저장하지 않음
- 번역·원문 복귀 후 내장 메뉴 상태를 잠시 확인하고 결과를 전달한 다음 종료

메뉴를 닫을 때는 해당 메뉴의 손쉬운 사용 취소 동작을 먼저 사용합니다. 대체 Escape 입력은 Safari가 맨 앞에 있을 때 Safari 프로세스에만 전달합니다.

권한 상태는 macOS의 TCC가 관리합니다. 앱은 시스템 권한 요청을 이미 시도했는지를 나타내는 boolean 하나만 `UserDefaults`에 저장하며, 사용자 정보는 저장하지 않습니다.

이후 권한이 없으면 명시적인 번역 시도 때 현지화된 복구 안내를 표시하며, 시스템 권한 창을 반복 요청하지 않습니다. macOS 27 설치 안내에는 실제 한국어 설정에서 확인한 ‘기기 제어 및 데이터 접근’ 패널 이름을 반영했습니다.

선택적인 명령줄 `--diagnose` 모드는 앱 버전·macOS 주 버전·현재 손쉬운 사용 신뢰 상태만 출력합니다. Safari 탐색, 권한 요청, 보고서 저장, 데이터 전송은 하지 않습니다.

## App Sandbox와 entitlement

- 컨테이너 앱: Safari UI 자동화를 위해 App Sandbox를 사용하지 않음
- 내장 Safari 확장: App Sandbox 사용
- 네트워크·파일·App Group·`get-task-allow` entitlement 없음
- 두 실행 타깃 모두 Hardened Runtime 사용

릴리스 스크립트는 `AXValue`, 네트워크·파일·클립보드 API, 확장 권한 또는 현지화 리소스가 의도치 않게 변경되면 실패합니다.

## 공개 전 점검

2026년 9월 19일 v1.2.0 소스와 공증된 DMG를 다시 점검했으며, 이 범위에서 불필요한
개인 경로·이메일·인증 정보·개인 키는 발견되지 않았습니다. 공개 Developer ID 서명자
정보는 유지됩니다. 릴리스에는 DMG와 체크섬만 첨부하며 로컬 로그·백업은 제외합니다.
실행 검증 범위는 [v1.2.0 검증 기록](TOGGLE.ko.md)을 참고하세요.

2026년 9월 15일 소스, 로컬에서 참조 가능한 Git 이력, 공증된 DMG, 내장 앱·확장,
이미지 메타데이터와 확장 속성을 점검했습니다. 이 범위에서 불필요한 개인 이메일,
홈 디렉터리 경로, 인증 정보, 개인 키는 발견되지 않았습니다. Git 작성자·커미터는
공개 GitHub 사용자명과 noreply 이메일을 사용합니다. 앱 아이콘 EXIF에는 픽셀 크기만
있으며 작성자·위치 정보는 없었습니다. 로컬 빌드 로그와 백업은 Git과 배포 첨부에서 제외합니다.

Developer ID 서명자 이름과 Team ID는 서명에 유지됩니다. DMG의 로컬 확장 속성에는
디스크 이미지 체크섬 메타데이터가 있으나, GitHub 첨부에는 해당 파일의 바이트만 전송되고
파일시스템 확장 속성은 포함되지 않습니다. 이번 점검이 모든 형태의 비밀 정보나 실행 문제를
완전히 배제한다는 보장은 아닙니다. 남은 수동 테스트는 [검증 범위](MACOS27.ko.md)를 참고하세요.
