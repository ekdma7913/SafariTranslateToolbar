# Safari Translate Toolbar 1.2.0

[KO](RELEASE_NOTES_1.2.0.ko.md) | [EN](RELEASE_NOTES_1.2.0.md)

- 한 번 누르면 번역하고 다시 누르면 원문으로 돌아갑니다. 클릭 횟수가 아닌 Safari의 실제 메뉴 상태로 동작을 결정합니다.
- 번역 상태가 확인되면 활성 아이콘과 `ON` 배지가 나타나고, 원문 복귀 시 꺼집니다. `…`는 처리 중, `?`는 미확인 상태이며 최종 툴바 색상은 Safari가 결정합니다.
- 탭별 표시를 분리하고 페이지 이동 시 초기화하며, 오래된 응답과 처리 중 연속 클릭을 무시합니다.
- `nativeMessaging` 최소 권한을 유지합니다. 웹페이지 본문·URL·제목 접근과 번역 상태 영구 저장은 없으며, 메시지에는 클릭별 무작위 UUID와 상태 결과만 추가했습니다.
- macOS 13 이상과 Apple Silicon·Intel universal 바이너리를 유지하며 Developer ID 서명과 Apple 공증을 완료했습니다.

Swift 8개와 JavaScript 11개 테스트를 통과했습니다. 한국어 macOS 27 / Safari 27의 설치 앱에서 번역 → 원문 → 재번역, 탭 전환, 새로고침을 확인했습니다.

배지는 마지막 확인 결과이며 Safari 자체 메뉴를 상시 감시하지 않습니다. 처리 중에는 같은 탭·창을 맨 앞에 유지하세요. 권한 거부·초기화, 여러 프로필, 영어 시스템 UI, 이전 macOS, Intel 기기, 느리거나 실패하는 번역은 추가 수동 확인이 필요합니다. [검증 기록](TOGGLE.ko.md)을 참고하세요.
