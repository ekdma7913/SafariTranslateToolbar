# Safari Translate Toolbar 1.0.0

English | [한국어](RELEASE_NOTES_1.0.0.ko.md)

Initial public release.

- Run Safari's built-in Apple translation from a toolbar button
- No separate translation service, webpage content script, account, or network communication
- Supports Apple Silicon and Intel Macs
- Developer ID signed, Apple notarized, and Gatekeeper verified
- Shows the Accessibility permission request only once

See the installation guide in the DMG or the README for setup instructions.
